# Code of Conduct

## Our Commitment

The NexusDeploy community is committed to fostering an open, welcoming, inclusive, and respectful environment for everyone.

We believe that healthy collaboration is built on mutual respect, constructive communication, and professionalism. Every contributor, regardless of experience level, background, or identity, deserves to participate in an environment free from harassment and discrimination.

By participating in this project, you agree to follow this Code of Conduct.

---

# Our Standards

Examples of behavior that contribute to a positive community include:

- Being respectful and courteous.
- Using welcoming and inclusive language.
- Providing constructive feedback.
- Respecting differing viewpoints and experiences.
- Accepting constructive criticism gracefully.
- Helping new contributors learn and grow.
- Prioritizing the project's long-term health over personal preferences.
- Collaborating in good faith.
- Focusing discussions on technical issues rather than individuals.

---

# Unacceptable Behavior

The following behaviors are not tolerated:

- Harassment, intimidation, or personal attacks.
- Discrimination based on personal characteristics.
- Hate speech or abusive language.
- Trolling or deliberately provoking conflict.
- Public or private harassment.
- Sharing another person's private information without permission.
- Repeatedly derailing discussions or pull requests.
- Spam, advertising, or unrelated promotional content.
- Knowingly submitting malicious code or intentionally harmful contributions.
- Any conduct that would reasonably make others feel unsafe or unwelcome.

---

# Scope

This Code of Conduct applies to all project spaces, including but not limited to:

- GitHub Issues
- Pull Requests
- Discussions
- Documentation
- Project communication channels
- Community events related to NexusDeploy

It also applies when representing the project in public spaces.

---

# Reporting Issues

If you experience or witness behavior that violates this Code of Conduct, please report it to the project maintainers.

When reporting an incident, include:

- A description of the behavior.
- Where it occurred.
- Any relevant links or screenshots.
- Any additional context that may help.

All reports will be handled confidentially whenever possible.

---

# Enforcement

Project maintainers are responsible for interpreting and enforcing this Code of Conduct.

Maintainers may take any action they deem appropriate in response to unacceptable behavior, including:

- Requesting changes in behavior.
- Editing or removing comments or content.
- Closing issues or pull requests.
- Temporarily restricting participation.
- Permanently banning contributors from the project.

Enforcement decisions will be made with the goal of maintaining a respectful and productive community.

---

# Good Faith

Mistakes happen.

Not every disagreement or misunderstanding is misconduct. Contributors are encouraged to assume good intent, communicate respectfully, and work together toward constructive solutions.
